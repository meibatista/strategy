Padrão Comportamental = Strategy : esse padrão define uma família de algoritmos, encapsula cada um deles em uma classe separada e os torna intercambiáveis, permitindo que o algoritmo varie independentemente dos clientes que o utilizam. Na sua implementação, cria-se uma interface comum que representa a estratégia e classes concretas que implementam diferentes variações dessa operação, permitindo alternar comportamentos em tempo de execução sem acoplamento rígido. No exemplo, EstrategiaPagamento define o contrato principal de pagamento, enquanto PagamentoCartao, PagamentoBoleto e PagamentoPix implementam as lógicas específicas de cobrança, sendo gerenciadas dinamicamente pela classe de contexto Pagamento.
